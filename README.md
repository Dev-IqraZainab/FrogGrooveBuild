## ✨ About

This repo hosts the **production build** of [FrogGroove](https://github.com/Dev-IqraZainab/FrogGroove), a playful 3D scene where animated frog characters dance in a forest under the sky, with music.
It's deployed with **GitHub Pages**, so anyone can open it instantly.

> 🧩 Source code lives in **[Dev-IqraZainab/FrogGroove](https://github.com/Dev-IqraZainab/FrogGroove)**. This repo has only the ready-to-run build.

## 🎮 Features

- 🐸 Animated 3D frog characters (idle & dance animations)
- 🦩 Extra characters like a flamingo
- 🌲 3D forest environment with a sky backdrop
- 🎵 Background music for the party vibe
- 🌐 Runs in any modern browser with no install

## 📁 Project Structure

```
FrogGrooveBuild/
├── assets/            # Bundled JS/CSS from the build
├── kermit_frog.glb    # Frog character model
├── basic_kermit.glb   # Base frog model
├── idle.glb, idleK.glb# Idle animations
├── Flamingo.glb       # Flamingo model
├── forest.glb         # Forest environment
├── sky.jpg            # Sky texture
├── music.mp3          # Background music
└── index.html         # Entry point
```

## 💻 Run Locally

```bash
git clone https://github.com/Dev-IqraZainab/FrogGrooveBuild.git
cd FrogGrooveBuild
npx serve .        # or: python -m http.server 8000
```
